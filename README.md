# brags

Agent skills and schemas for maintaining a private accomplishment warehouse.

## Skills

- `brag-capture` gathers possible accomplishments and supporting behavioral evidence into a private warehouse.
- `brag-review` removes routine activity, merges related records, promotes meaningful accomplishments, and builds behavioral interview stories.

```text
evidence -> inbox candidates -> reviewed entries -> interview stories
```

The public repository contains only skill instructions and schemas. Personal accomplishment records belong in a separate private Git repository configured through `$BRAG_HOME`.
